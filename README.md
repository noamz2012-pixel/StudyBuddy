# FitTrack 💪

**אפליקציית מעקב כושר מקיפה**

FitTrack היא אפליקציית מעקב כושר מודרנית ומתקדמת המאפשרת למשתמשים להנהל אימונים, תזונה, תוכניות אימון ומעקב התקדמות בממשק משתמש דינמי עם ממשק דארק תימ מיוחד בעיצוב ירוק ושחור.

## 🔧 טכנולוגיה

- **Next.js 16.1.6** עם TypeScript
- **Firebase Authentication** לאימות מאובטח
- **Firestore** לאחסון נתונים בזמן אמת
- **Tailwind CSS** לעיצוב
- **Cloud Functions** לשירותי דוא"ל ותזכורות

## 🌍 עמודים ודפים עיקריים

- 🔐 **מערכת אימות** - הרשמה והתחברות דרך Firebase עם אימות דוא"ל
- 📊 **לוח בקרה** - סיכום כללי של קלוריות, חלבון, אימונים, משקל ופעולות מהירות
- 🍽️ **תזונה** - מעקב יומי של מקרו-נוטריינטים (קלוריות, חלבון, פחמימות, שומנים)
- 💪 **אימונים** - ניהול תוכניות אימון, מעקב סדרות ורפטיציות, היסטוריית אימונים
- 📈 **התקדמות** - מעקב משקל עם גרפים, סטטיסטיקות יומיות, מדידות גוף
- 📋 **תוכניות** - ספריית תוכניות אימון, בחירה והפעלה של תוכניות
- 👤 **פרופיל** - ניהול פרטי משתמש, הצגת סטטיסטיקות, אימות דוא"ל
- ⚙️ **הגדרות** - הגדרת יעדי קלוריות וחלבון, בחירת יחידות, תזכורות והודעות

## ✨ תכונות מתקדמות

✅ ממשק דארק תימ - עיצוב ירוק על שחור עם אנימציות חלקות  
✅ AI Coach - יעוץ אישי מותאם למשתמש  
✅ תזכורות מתוזמנות - התראות אוטומטיות לאימונים ותזונה

✅ סנכרון Firebase - אחסון בענן עם גישה מכל מכשיר

## 🚀 התקנה והרצה

1. שכפל את הפרויקט:
```bash
git clone https://github.com/noamz2012-pixel/StudyBuddy.git
cd StudyBuddy
```

2. התקן תלויות:
```bash
npm install
```

3. הגדר משתני סביבה:
- העתק את `.env.example` ל-`.env.local`
- הוסף את פרטי Firebase שלך מ-[Firebase Console](https://console.firebase.google.com/)

4. הרץ את שרת הפיתוח:
```bash
npm run dev
```

5. פתח [http://localhost:3000](http://localhost:3000) בדפדפן

**הערה:** שם המאגר הוא StudyBuddy אך האפליקציה שונתה ל-FitTrack - אפליקציית מעקב כושר מקיפה.
