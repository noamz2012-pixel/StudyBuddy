# StudyBuddy
AI-powered study assistant for students

## About / אודות
StudyBuddy is an AI-powered platform designed to help students learn more effectively. This repository is actively developed with the assistance of GitHub Copilot AI agents.

StudyBuddy היא פלטפורמה מונעת AI שנועדה לעזור לתלמידים ללמוד ביעילות רבה יותר. מאגר זה מפותח באופן פעיל בסיוע סוכני AI של GitHub Copilot.
